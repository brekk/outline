## Usage

By default, for convenience, just running `outline` with no arguments will infer `outline --cwd .`

```shell
outline
```
You can run it with a `--help` / `-h` flag to get a listing of all the flags it takes. They're pretty straightforward.

`--cwd` / `-c`
Set current working directory. Defaults to `./`

`--force` / `-f`
Overwrite files rather than emitting warnings. Only use this if you really want to, and probably only in version control. Use at your own risk.
